# Data and provenance

The runnable experiment uses original synthetic drawings generated by `src/trackingquick/synthetic.py`; it downloads no external images or labels. The DINOv2 backbone is pretrained by its original authors; the verifier prototypes use 16 generated reference crops, with 12 separately seeded validation crops. Test trajectories use seeds 42 and 73, each 180 frames at 30 Hz.

Only small augmentation is used: brightness/background variation, modest orientation and size changes, and three-pixel directional blur on a subset of reference crops. Test sequences include lighting change, five-pixel blur, and a fifteen-frame occlusion. Reference seeds and test seeds differ, but the renderer is shared: this is a synthetic engineering test, not evidence of real-data generalization.

The conditional flow-matching experiment has its own generated motion samples and separate evaluation seed. It never uses camera observations or test-trajectory labels for training.

Candidate public-data sources and licensing are recorded in [the research notes](../docs/RESEARCH_NOTES.md). Large source/derived files remain ignored by Git. Before using real footage, record source, revision, license, annotation definition, camera calibration and flight-level split.
